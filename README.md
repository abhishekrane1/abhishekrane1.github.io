# Abhishek Rane – Portfolio

Personal portfolio for Abhishek Rane, Data Analytics Engineer (SQL, ETL, Power BI, QlikSense, Snowflake, Azure Data Factory).

A single static page: `index.html`. No build step, no dependencies. Fonts load from Google Fonts.

## Run locally

Open `index.html` in a browser.

## Host free on GitHub Pages

1. Create a new repository on GitHub, for example `portfolio` (or `<username>.github.io` for a root URL).
2. Upload `index.html` and `README.md` to the repository.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**, choose the `main` branch and the `/ (root)` folder, then save.
5. After a minute or two the site is live at `https://<username>.github.io/<repo-name>/`.
